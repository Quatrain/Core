# @quatrain/i18n

> 📦 **API Reference**: Detailed TypeScript documentation, classes, interfaces, and methods are available in the [TypeDoc API Reference for @quatrain/i18n ↗](/api-reference/modules/_quatrain_i18n.html).

A framework-agnostic central internationalization (i18n) and translation registry system for the Quatrain Core monorepo.

## Installation

This package is managed internally within the workspaces:
```json
"dependencies": {
  "@quatrain/i18n": "workspace:*"
}
```

    Class MapProperty

    A property type designed to store arbitrary JSON objects or Key-Value maps.

    Example

    const metadata = new MapProperty({
       name: 'metadata',
       defaultValue: {}
    });

    metadata.set({ theme: 'dark', version: 2 });
